The excluded TCP-confinement test was also run without filtering and failed:
this host has Landlock ABI 3, while TCP restriction requires ABI 4. This is
a real kernel limitation. No TCP isolation is claimed on this test host.
Device ioctl restriction requires ABI 5 and is likewise unavailable here.
The runtime reports these limitations in its cage description.

Two runtime portability faults encountered during validation were corrected:
absent default system directories no longer prevent a cage from being built,
and filesystem rights are matched to the kernel ABI. Raw syscall failures
now report their actual errno instead of a stale libc errno. Existing tests
verify that file access outside the workspace remains denied.

Provider quota responses were tested with fixtures using the documented
Ollama Cloud and OpenRouter formats. No live provider credentials or paid
model calls were used. Other providers expose session tokens where reported
and explicitly mark account quota unavailable.
